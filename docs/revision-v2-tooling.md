# Revision tooling and disclosure

Codex assisted with experiment orchestration, implementation, manuscript/site
editing, and inline adversarial self-checks. These self-checks are not independent
peer reviews. Human authors remain responsible for scientific claims, citations,
data rights and submission decisions. Generated engineering pilots are labeled
separately from the predeclared learning evaluation.

The scientific-visualization skill supplied procedural figure-integrity and
export checks. Software-workflow attribution: Timothy Kassis, Vinayak Agarwal,
Yuhuan He, Darshil Patel and Aubrey M. Brueckner (2026), *Scientific Agent Skills:
A Library of Procedural Knowledge for Research Agents*,
[arXiv:2609.00065](https://doi.org/10.48550/arXiv.2609.00065).
Metadata was checked against the current arXiv record on29 September2026. This is
an attribution of tooling, not evidence supporting the benchmark's physical or
learning results.
